                                                                                                                                       | A Timestamp represents a point in time independent of any time zone or local<br/> calendar, encoded as a count of seconds and fractions of seconds at<br/> nanosecond resolution. The count is relative to an epoch at UTC midnight on<br/> January 1, 1970, in the proleptic Gregorian calendar which extends the<br/> Gregorian calendar backwards to year one.<br/><br/> All minutes are 60 seconds long. Leap seconds are "smeared" so that no leap<br/> second table is needed for interpretation, using a [24-hour linear<br/> smear](https://developers.google.com/time/smear).<br/><br/> The range is from 0001-01-01T00:00:00Z to 9999-12-31T23:59:59.999999999Z. By<br/> restricting to that range, we ensure that we can convert to and from [RFC<br/> 3339](https://www.ietf.org/rfc/rfc3339.txt) date strings.<br/><br/> # Examples<br/><br/> Example 1: Compute Timestamp from POSIX `time()`.<br/><br/>     Timestamp timestamp;<br/>     timestamp.set_seconds(time(NULL));<br/>     timestamp.set_nanos(0);<br/><br/> Example 2: Compute Timestamp from POSIX `gettimeofday()`.<br/><br/>     struct timeval tv;<br/>     gettimeofday(&tv, NULL);<br/><br/>     Timestamp timestamp;<br/>     timestamp.set_seconds(tv.tv_sec);<br/>     timestamp.set_nanos(tv.tv_usec * 1000);<br/><br/> Example 3: Compute Timestamp from Win32 `GetSystemTimeAsFileTime()`.<br/><br/>     FILETIME ft;<br/>     GetSystemTimeAsFileTime(&ft);<br/>     UINT64 ticks = (((UINT64)ft.dwHighDateTime) << 32) \| ft.dwLowDateTime;<br/><br/>     // A Windows tick is 100 nanoseconds.
